## 🎯 About

POL Finance is a web3 protocol optimization platform that focuses on securing and enhancing the economic and financial mathematics behind blockchain protocols. Built with Gatsby.js, this project provides a modern, performant, and accessible web interface.

## ⚙️ Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (version specified in `.nvmrc`)
- npm or yarn package manager
- Git

## 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/pol-finance.git
cd pol-finance
```

2. Install dependencies:

```bash
# Using npm
npm install

# Or using yarn
yarn install
```

3. Set up environment variables:

```bash
cp .env.example .env
```

Edit the `.env` file with your configuration values.

## 🚀 Usage

### Development Mode

To start the development server:

```bash
# Using npm
npm run develop

# Or using yarn
yarn develop
```

The site will be available at `http://localhost:8000`

### Production Mode

To serve the production build:

```bash
# Using npm
npm run serve

# Or using yarn
yarn serve
```

## 💻 Development

- `npm run develop` or `yarn develop` - Start development server
- `npm run clean` or `yarn clean` - Clear Gatsby cache
- `npm run test` or `yarn test` - Run tests (currently placeholder)

## 🏗️ Building for Production

To create a production build:

```bash
# Using npm
npm run build

# Or using yarn
yarn build
```

The production build will be available in the `public` directory.
